## 2. PostgreSQL 的全文检索能力

发布方：PostgreSQL 项目。

核对范围：PostgreSQL 17 官方文档第 12.1 节。

可核对的技术事实：PostgreSQL 的全文检索功能可以查找符合查询的自然语言文档，并支持按与查询的相关性排序。

适用参考：讨论关键词／全文检索的实现路线。

不能推出：当前 SalesMind AI 已采用全文检索、已经实现中文分词、已实现语义理解，或已达到某项性能指标。当前项目的向量检索不等于已实现 PostgreSQL 全文检索。

来源：[PostgreSQL 17：全文检索介绍](https://www.postgresql.org/docs/17/textsearch-intro.html)。

## 3. pgvector 的向量检索能力

发布方：pgvector 项目维护者。

核对范围：官方 GitHub README；在线内容会随版本变化，实际安装版本需另行核对。

可核对的技术事实：pgvector 为 PostgreSQL 提供向量存储和相似度检索能力。

可核对的技术事实：pgvector 支持余弦距离等距离度量。

可核对的技术事实：pgvector 提供精确最近邻检索，也提供近似最近邻索引方案。

适用参考：评估是否在 PostgreSQL 中保存文档向量并执行相似度检索。

不能推出：当前部署已经创建 HNSW／IVFFlat 索引、已经调优、检索结果必定正确，或支持某个 QPS／延迟／容量。检索到近邻不等于语义结论真实，也不等于事实已批准。

来源：[pgvector 官方 README](https://github.com/pgvector/pgvector)。

## 4. BGE-M3 的检索能力

发布方：BGE 项目官方文档。

核对范围：BGE-M3 模型说明。

可核对的技术事实：BGE-M3 是面向多语言检索的 embedding 模型。

可核对的技术事实：该模型支持 dense、sparse 与 multi-vector 检索表示。

适用参考：讨论文本如何转换为检索表示，以及多语言文档的检索技术选择。

不能推出：当前项目已经同时采用三种检索方式、已经本地托管模型，或能够回答文档中没有的信息。模型本身的能力不能证明某个 API 服务实际开放了全部功能。

来源：[BGE-M3 官方说明](https://bge-model.com/bge/bge_m3.html)。
