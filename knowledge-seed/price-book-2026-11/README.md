# 参考价目表（2026-11）

这不是本公司的报价口径。它是**按公开挂牌价推导出来的一套可用价目**，目的是让报价功能在拿到真实价格之前就能跑通，并且每个数字都能追溯到一条可点开的链接。

## 怎么用

```bash
python manage.py import_price_book knowledge-seed/price-book-2026-11/prices.csv --dry-run
python manage.py import_price_book knowledge-seed/price-book-2026-11/prices.csv
```

导入后每条的 `category` 都是「参考价」、名称里带「（参考价）」——它会跟着报价行一路显示到导出的报价页上，不会被误认为正式报价。拿到真实价格后：导入真价目、把这批参考行在 Admin 里停用、重新报价。

## 需要你知道的三件事

1. **只有两个假设**：知识库授权的 50% 档位、年维护费的 20%。其余要么是公开挂牌价的直接采用，要么是写清楚的乘除法；
2. **锚点是 2024–2026 年的挂牌价**，厂商调价后需要重新采样；
3. **参考价不含折扣、税费与地区差异**。它们进系统后仍然是普通价目行，折扣闸门（默认 15%）照常生效。

## 为什么不用 `is_sample`

`is_sample` 是「编出来的占位数据」的标记，带它的报价页不允许导出。这批数字有公开依据、可以对外解释，所以按真实条目导入；区分它们靠的是名称与分类里的「参考价」字样，以及本文档。

如果你们希望它们在换成真价之前**也不可导出**，把 `prices.csv` 的导入改成带 `is_sample=True` 的版本即可——说一声我改。
